# Support

MIA is an early vibe-coded alpha maintained on a best-effort basis. There is no
guaranteed response time, compatibility promise, or commercial support channel.

Before opening an issue:

1. Read `docs/TROUBLESHOOTING.md`.
2. Run `mia --version`, `mia doctor`, `mia plugins`, and `mia pkg doctor`.
3. For installer problems, run the equivalent command with `--dry-run`.
4. Reproduce with a non-sensitive test target where possible.
5. Remove personal data, API keys, tokens, absolute case paths, raw reports, and
   package state containing private paths.
6. Include OS, architecture, package manager, Python version, MIA version,
   selected profile/group, exact command, and sanitized error output.
7. State whether the command was installed by MIA or discovered externally.

General questions belong in GitHub Discussions if enabled. Reproducible defects
belong in Issues. Follow `SECURITY.md` for vulnerabilities.

MIA maintainers cannot provide support for paid API accounts, upstream bans,
service-specific access decisions, or legal authorization questions.
